# Constitution

1. The shared query key is verified only on the server, never committed, and never logged by application code.
2. Browser code never receives the Supabase service-role key; database tables expose no anonymous policy.
3. Rankings are derived from match results, never edited as duplicated totals.
4. Every mutation names an actor and appends an audit record. Deletion is soft and restorable.
5. Historical source images and uncertain transcriptions stay distinguishable from verified structured data.
6. Every dispatchable path resolves to exactly one leaf layer; required CI audits the whole routing tree.
